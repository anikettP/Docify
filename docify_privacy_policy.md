## 1. Information Processed

Depending on the features a user chooses to use, Docify may process:

- **Webpage content:** Content from a webpage that the user asks Docify to convert into a document.
- **Selected text:** Text the user selects to create a document from a portion of a webpage.
- **Browser-tab information:** Information about tabs the user chooses for multi-tab document creation.
- **Preferences and documents:** Settings, document content, and document history, depending on the extension's implemented storage features.

## 2. How Information Is Used

Information is processed to provide Docify's core features, such as creating, formatting, editing, refining, and exporting documents. Docify should not use information for purposes unrelated to these features unless those purposes are clearly disclosed and any required consent is obtained.
